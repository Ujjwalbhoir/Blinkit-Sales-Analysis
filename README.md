# Blinkit Sales Dashboard (Power BI)

## Overview
This project contains a **Power BI dashboard** built using Blinkit sales and outlet data. The dashboard provides insights into sales performance, outlet characteristics, item distribution, customer ratings, and product categories to support data-driven decision-making.

## File Included
- `blinkit(1).pbix` – Power BI report file

## Dashboard Highlights

### KPI Cards
- Total Sales
- Average Sales
- Number of Items
- Average Rating

### Visualizations
- Sales by Fat Content
- Fat Content by Outlet
- Outlet Establishment Trend
- Outlet Size Distribution
- Outlet Location Analysis
- Product / Item Type Analysis
- Detailed Summary Table

### Filters
- Outlet Type
- Item Type
- Other interactive slicers available within the report

## Business Questions Answered
- Which outlet types generate the highest sales?
- How does fat content impact sales performance?
- Which outlet locations contribute the most revenue?
- How are sales distributed across outlet sizes?
- What are the top-performing product categories?
- How do customer ratings compare across segments?

## Tools & Technologies
- Power BI Desktop
- Data Modeling
- DAX Measures
- Interactive Visualizations
- Dashboard Design

## Key Insights
- Compare sales performance across outlet categories.
- Identify high-performing outlet locations.
- Analyze customer preferences through item categories.
- Monitor overall business KPIs from a single dashboard.

## How to Use
1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Refresh the dataset if required.
4. Explore the interactive dashboard using filters and slicers.
